The link that opened this page carries a single-use enrolment code. This page never reads it: it stays in your browser, after the #. The code expires (24 hours by default) and stops working once a machine has used it. Do not forward the link.

1. Before you start

You need git, jq, uv (or python3 -m venv), curl, tar and the Claude Code CLI (claude).

2. Clone the repository

Clone the Loom repository your team uses, and keep the checkout: the client is installed from it.

git clone <repo-url> loom && cd loom

3. Install the client

bash client/install.sh

4. Enrol this machine

~/.loom/venv/bin/loom enroll

Paste this whole link into loom enroll at its hidden prompt. It carries both this server's address and the code; nothing is echoed, and nothing lands in your shell history. Your machine then mints its own device token, which never travels.

5. Check the environment

~/.loom/venv/bin/loom doctor
